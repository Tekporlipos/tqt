About

A software-first investment firm

Tekpor Quant Technologies builds and runs its own automated investment system, and shows the results publicly.

Who we are

Tekpor Quant Technologies designs the strategies, builds the platform and manages the portfolio in-house. The work started live in December 2024. Today the system is a Flask backend connected to MetaTrader 5, with a public dashboard and a protected admin console.

Keeping the process in-house lets us move quickly, keep it simple, and stand behind every number on the dashboard.

Principles

  • Write the rule down, then follow it
  • Stop first, size second
  • Publish the result, good or bad
  • Build the structure before taking anyone's money
Technology

What it runs on

Execution

MetaTrader 5 for order execution, a Python service for signals, sizing and rotation.

Data

One-minute equity and unrealized P&L snapshots, stored and charted as candles or lines.

Dashboard

A static React site, with its API reached through a Cloudflare tunnel.

Security

Admin sessions are signed and expire after an hour. Public pages expose results only.
